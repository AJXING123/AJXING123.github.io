Linux 文件系统与基础命令学习手册

本文最后更新于 2026年10月17日 上午

学习目标

掌握Linux文件系统树形结构与路径规则，熟练使用目录浏览、文件增删改移、内容查看类基础命令，能够独立完成日常文件操作与简单目录运维。

一、核心知识体系

1.1 文件系统结构

Linux采用单根树形目录结构，所有文件从根目录 / 开始，没有Windows的C/D盘符概念。

目录 用途说明
/home 普通用户家目录，每个用户对应一个子目录，可自由读写
/etc 系统与软件配置文件存放目录
/opt 第三方软件安装目录（ROS默认安装路径）
/var/log 系统日志存放目录
/tmp 临时文件目录，系统重启后里面文件可能清空

核心原则：系统级目录谨慎修改，用户家目录（~）是你的自由操作区。

1.2 路径与特殊符号

在Linux中路径分为绝对路径和相对路径。

  • 绝对路径：以 / 开头，从根目录起始，位置固定，示例：/home/user/file.txt
  • 相对路径：以当前目录为起点，示例：Documents/file.txt

下面是开发中高频使用的路径特殊符号：

符号 含义
. 当前目录
.. 上一级目录（父目录）
~ 当前用户的家目录
- 上一次所在目录（仅 cd 命令支持）

1.3 目录浏览命令

目录浏览是使用Linux最基础的操作，我们需要随时确认自己所在位置，查看文件夹内文件。

命令 功能 常用用法/参数
pwd 打印当前工作目录的绝对路径 直接执行，用于确认当前所在位置
ls 列出目录内容 -l：长格式显示文件详情
-a：显示隐藏文件
-h：人性化展示文件大小
组合推荐：ls -lah
cd 切换工作目录 cd ~：返回家目录
cd ..：返回上一级目录
cd -：快速返回上一次所在目录
cd /：进入根目录

实操讲解

  1. 当你不确定自己当前在哪个文件夹时，直接输入pwd，终端就会输出当前目录完整路径。
  2. ls用来查看文件夹里有哪些文件。单独ls只显示文件名；ls -l会展示权限、所有者、大小、修改时间；ls -a会把以.开头的隐藏文件一并展示。ls -lah是日常开发最常用组合。
  3. cd用于跳转目录。cd ~一键回到自己家目录；cd ..向上跳一级；cd -可以在两个目录来回切换，适合来回对比两个文件夹。

1.4 文件与目录操作命令

创建、删除、复制、移动、重命名是日常开发最高频的文件操作，ROS开发中搭建功能包目录时会大量使用。

命令 功能 关键注意事项
mkdir 创建目录 -p 参数用于递归创建多层嵌套目录
touch 创建空文件 / 更新文件时间戳 文件不存在则新建；文件已存在则刷新修改时间
rm 删除文件/目录 删除文件夹必须添加 -r 参数
-rf：强制递归删除，执行前务必核对路径
cp 复制文件/目录 复制整个目录必须加 -r 参数
语法：cp 源路径 目标路径
mv 移动文件 / 重命名 同目录下执行mv等价于重命名
语法：mv 源路径 目标路径

实操讲解

  1. mkdir默认只能创建单层目录。如果需要一次性创建多级嵌套文件夹，必须加上-p参数，例如mkdir -p project/src。
  2. touch核心两个作用：文件不存在就新建空白文本文件；文件已经存在，不会修改内容，只会更新文件最后的修改时间。
  3. rm删除操作没有回收站，文件删除后很难恢复。删除文件夹时必须加-r；rm -rf强制删除，不会弹出确认提示，使用一定要谨慎。
  4. cp复制文件直接使用；如果复制整个文件夹，必须加-r参数，否则会报错。
  5. mv：如果源文件和目标文件在同一个文件夹，作用就是重命名；如果目标路径是别的目录，作用就是移动文件。

1.5 文件内容查看命令

在开发中我们经常要读取配置文件、查看运行日志，不同场景选用不同查看命令。

命令 适用场景 常用操作
cat 查看短小文本文件 一次性输出文件全部内容
less 浏览长文件、大日志 空格向下翻页，b向上翻页，/关键词搜索，q退出
head 查看文件开头内容 默认读取前10行；-n N 指定读取N行
tail 查看文件末尾内容 默认读取最后10行；-f 实时跟踪新增内容，Ctrl+C停止

实操讲解

  1. cat适合几十行以内的短文件，会一次性把全部内容打印到终端，文件太长会刷屏。
  2. less是分页阅读器，打开长日志不会一次性加载全部内容。打开后空格向下翻页，b向上翻页，输入/加上关键词可以搜索文本，按q退出阅读器。
  3. head用来查看文件开头，head -n 5 app.log代表只读取日志前5行。
  4. tail查看文件末尾，查看日志最常用。tail -f会持续监听文件，一旦文件新增日志就实时打印，调试ROS节点输出日志时非常好用，Ctrl+C终止监听。

二、分步实操练习

本章节为循序渐进的实操训练，跟着练习可以巩固上面所有基础命令。

阶段1：目录定位与浏览

目标：建立路径位置感，熟练切换目录
我们依次练习查看当前路径、浏览目录、文件夹跳转。

  1. 使用pwd确认当前所在目录。
  2. 使用ls、ls -l、ls -lah三种方式查看家目录内文件，对比输出结果差异。
  3. 切换到系统临时目录/tmp，执行pwd验证当前位置，查看目录内容。
  4. 执行cd ..回到上级根目录，用pwd确认。
  5. 使用cd ~快速返回家目录，pwd验证。
  6. 使用cd -在两个目录来回切换，感受快速跳转的便捷。

阶段2：创建与删除操作

目标：掌握目录和文件的新建、删除

  1. 回到家目录，创建linux_practice练习文件夹，进入这个目录，确认当前路径。
  2. 使用mkdir -p一次性创建多层目录project/src和project/logs，使用ls -R查看完整目录树。
  3. 创建空白文件readme.txt，同时在src文件夹下创建main.py、utils.py两个源码文件，查看src目录。
  4. 删除练习：新建test_del.txt，查看文件，执行rm删除；再创建嵌套文件夹test_dir/sub，使用rm -r删除整个目录。

阶段3：复制与移动操作

目标：掌握文件复制、移动、重命名

  1. 复制readme.txt，生成备份文件readme_backup.txt，查看目录验证。
  2. 复制整个project文件夹，命名为project_copy，ls -R查看复制后的完整目录。
  3. 使用mv命令，将readme_backup.txt重命名为README_backup.txt。
  4. 将重命名后的README_backup.txt移动到project目录内，查看project目录确认。

阶段4：文件内容查看

目标：适配不同场景的文件查看需求
我们先创建一份测试日志文件用于练习。

  1. 使用cat查看readme.txt短文件。
  2. 使用head读取日志前5行，tail读取日志末尾5行。
  3. 使用less分页浏览日志文件，熟悉翻页、搜索、退出操作。
  4. 使用tail -f实时跟踪日志新增内容，使用Ctrl+C结束监听。

三、综合实战项目：模拟ROS工作空间搭建

项目目标

模拟ROS2开发场景，完成工作空间目录搭建、文件布置、备份、整理、日志监控全流程，覆盖前面全部基础命令。

最终目录结构

操作步骤

步骤1：创建目录结构

回到家目录，使用mkdir -p一次性创建ros2工作空间完整目录树，创建完成后使用ls -R查看完整目录，核对文件夹结构是否和预期一致。

步骤2：创建初始文件

进入ros2_ws的src源码目录，分别为robot_base、robot_vision、robot_control三个功能包创建package.xml和CMakeLists.txt配置文件。
然后在config文件夹创建参数配置文件params.yaml，logs文件夹创建runtime.log日志文件。

步骤3：写入测试数据

编辑params.yaml配置文件，写入机器人名称、最大速度等配置参数。
生成模拟节点运行日志，用来测试日志查看命令。

步骤4：文件备份与整理

  1. 将src源码文件夹完整复制备份到backup目录下，作为项目备份。
  2. 将params.yaml配置文件，复制分发到三个功能包目录。
  3. 使用mv命令，把robot_base功能包重命名为robot_chassis。

步骤5：内容查看与监控

  1. 使用cat查看params.yaml配置文件，核对写入的参数。
  2. head、tail查看日志文件首尾内容。
  3. less分页浏览完整运行日志。
  4. tail -f实时监控runtime.log，模拟ROS节点运行日志输出。

步骤6：清理与收尾

删除backup目录里旧的源码备份文件夹，删除robot_vision功能包里多余的params.yaml配置副本。最后执行ls -R查看整个ros2_ws完整目录，完成项目。

四、常见易错点与学习提示

  1. 路径大小写敏感：Linux系统下 Documents 和 documents 是两个完全不同的目录，输入命令时注意大小写拼写。
  2. 删除操作谨慎：rm 删除文件没有回收站，一旦删除很难恢复；执行 rm -rf 之前，先用ls确认目标路径。
  3. 目录操作参数：复制、删除文件夹的时候，必须带上 -r 参数，直接对目录执行cp或rm会报错。
  4. 空格路径处理：如果路径名称包含空格，要用双引号包裹，例如 cd "My Documents"。开发项目路径尽量避免空格。
  5. 学习技巧：不用死记硬背全部命令，多使用Tab键自动补全路径，结合实操练习加深记忆。

结语

本篇手册覆盖Linux文件系统和文件操作全部基础能力，也是ROS开发的前置必备技能。熟练掌握这些基础命令，就可以独立完成ROS工作空间管理、配置文件维护、日志查看调试，为后续机器人开发打好基础。
