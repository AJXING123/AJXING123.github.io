TurtleBot3 多点定点导航项目

基于 Ubuntu 22.04 + ROS 2 Humble + Gazebo Classic 搭建 TurtleBot3
Burger 仿真导航系统，实现从建图、定位到多点定点导航，并通过 Python 与
Bash 脚本完成自动化。

一、项目介绍

本项目的目标是在 Gazebo Classic 中搭建 TurtleBot3 Burger
仿真环境，并基于 ROS 2 Humble 完成一套完整的移动机器人导航流程：

  • 在 Gazebo 中运行 TurtleBot3 Burger
  • 使用 LiDAR 进行环境感知
  • 使用 SLAM Toolbox 完成环境建图
  • 保存二维栅格地图
  • 使用 AMCL 在已知地图中进行定位
  • 使用 Nav2 完成路径规划与运动控制
  • 使用 Python Action Client 实现多目标点顺序导航
  • 使用 Bash 脚本将 Gazebo、Nav2、AMCL 和多点导航程序串联起来

最终实现：

机器人能够在 Gazebo 中依次前往四个预先记录的目标点。

当前项目重点是多点定点导航，不以复杂动态避障为目标。

ROS 2 DDS 网络发现问题

排查过程中发现本机存在 FlClash 网络接口，ROS 2
多播流量一度经过该接口，导致节点发现和服务通信出现异常。

这个问题说明：

ROS 2 节点”看不到彼此”时，不一定是节点没有启动，也可能是 DDS Discovery
的网络路径出现问题。

自动启动时序问题

start_nav.sh 曾出现启动后等待 AMCL 的情况，但重新运行后又成功完成整个
P1→P2→P3→P4 导航。

因此目前将其视为：

启动阶段可能存在偶发的 ROS 2
节点发现/启动时序问题，后续可以继续优化启动脚本。
